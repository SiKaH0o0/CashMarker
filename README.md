# CashMarker

轻量、模块化的个人记账网站，采用 Todoist 风格的快速录入方式。目前是可在本地使用的早期版本，云端同步和 PWA 安装能力尚未完成。

## 当前页面

- `/today`：自动读取当天日期，按标签录入并保存当天金额。
- `/month`：用折线图查看每日开销，并进入单日账单和支出构成。
- `/dashboard`：当前资金、预算剩余和待确认账单模块。
- `/bills`：逐条确认或跳过固定账单。
- `/reports`：已结算月报和当前月份未结算状态。
- `/settings`：首页模块开关和基础规则摘要。

## 本地运行

### Windows 双击启动（推荐）

在项目根目录双击 `启动 CashMarker.bat`。启动器会在后台运行开发服务器，等待网站就绪后自动用默认浏览器打开。使用结束后，双击 `停止 CashMarker.bat`。

BAT 窗口只在调用后台启动器时短暂闪现；Next.js 服务器本身不会占用一个持续显示的命令行窗口。

运行日志保存在 `.runtime/`，该目录不会提交到 Git。

### 命令行启动

```bash
pnpm install
pnpm dev
```

复制 `.env.example` 为 `.env.local`，并填写本机账单 Markdown 文件路径。Supabase 配置目前只是为后续云端同步预留，没有云端项目也可以运行。

## 当前数据范围

- 手动账目、标签和确认状态暂存在浏览器 `localStorage` 中。
- 同一浏览器刷新后数据仍然存在，但不同浏览器和设备之间暂时不会同步。
- `.env.local`、账目数据和本地运行日志不会提交到 Git。
- 固定账单页面只读取你在 `CASHMARKER_BILLS_MD_PATH` 中指定的 Markdown 文件。

## 核心规则

1. 金额以“分”的整数保存。
2. 待确认固定账单不扣除当前资金。
3. 每条固定账单单独确认、修改或跳过。
4. 月末仍有待确认账单时不能生成确切积蓄。
5. 首页模块显示设置不会改变底层账目。

详细边界见 `docs/architecture.md`。
